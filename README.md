## Notes

This program creates an interactive display of data using D3.js to creating a treemap visualization suitable for looking at hierarchies.

## Environment

* Operating System: Mac
* Browser: Chrome

## Included Files

* README.md -- this file
* index.html
* a08.js
* flare.js
* d3.js
* test-cases.js

## How to Run

To run this project, simply open the index.html file in a modern browser. The JavaScript is automatically applied as long as all files remain in the same directory. Datasets can be changed from the commenting/uncommenting different datasets at the top of a08.js

## References

No external resources were used in this project. Aside from the provided files, all SVG, CSS, and JS elements were designed and implemented from scratch.
